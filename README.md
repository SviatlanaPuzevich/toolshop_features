# Test Automation Assignment

## Overview

This project contains Gherkin feature files covering the main user flows of the e-commerce application.

The following areas are covered:

* Sign Up
* Sign In
* User Profile Management
* Product Details Page
* Product Search
* Product Categories
* Product Filters and Sorting
* Favorites
* Basket
* Checkout Authentication Flow
* Language Switching

---

## Test Coverage

### Authentication

* User registration
* User login with email/password
* User login with Google authentication
* Password validation
* Account creation during checkout

### User Profile

* View and update profile information
* Password change
* Two-Factor Authentication setup

### Product Catalog

* Product details display
* Product search
* Product categories
* Product filtering
* Product sorting

### Shopping Experience

* Favorites management
* Basket management
* Checkout authentication flows
* Guest checkout

### Localization

* Language switching
* Language persistence

---

## Notes

The scenarios focus on the most important business flows and validation rules. UI styling, responsiveness, browser compatibility, and non-functional testing are out of scope.
